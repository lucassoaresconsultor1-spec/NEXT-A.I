# NEXT A.I — identidade visual (conceito 01B · Avanço Sólido)

Logo escolhido: N sólido cuja haste direita sobe em seta (avançar, crescer) e o nome "NEXT" com "A.I" numa pílula lima. Geometria idêntica ao artboard "01B · Avanço Sólido" do canvas de logos.

## Cores

| Nome | HEX | Uso |
|---|---|---|
| Verde-floresta | `#062F28` | Base do ícone, texto, fundos escuros |
| Lima | `#9FE870` | Seta, pílula "A.I", destaques |
| Verde-floresta 2 | `#0E453A` | Seta no símbolo sobre fundo claro |
| Cinza | `#7B7B7B` | Textos de apoio |
| Branco | `#FFFFFF` | Haste do N sobre fundo escuro, fundos |

Lima sobre branco tem pouco contraste (1,4:1): use o lima como preenchimento ou destaque, nunca como cor de texto sobre branco.

## Tipografia de apoio

Urbanist (títulos e números) e Plus Jakarta Sans (texto), ambas do Google Fonts. O nome "NEXT A.I" no logo é desenhado em vetor e não depende de fonte.

## Arquivos

`svg/` (vetor, use sempre que possível):

| Arquivo | Quando usar |
|---|---|
| `logo-horizontal.svg` | Fundo claro (padrão) |
| `logo-horizontal-negative.svg` | Fundo escuro (texto branco) |
| `logo-horizontal-mono.svg` | Uma cor só (impressão, carimbo, fundo lima) |
| `logo-vertical.svg` | Espaços quadrados ou estreitos |
| `wordmark.svg`, `wordmark-negative.svg` | Só o nome |
| `icon.svg`, `icon-lime.svg` | Ícone de app, avatar, favicon |
| `symbol.svg`, `symbol-negative.svg`, `symbol-mono.svg` | Símbolo sem o quadrado de fundo |

`png/` (fundo transparente): ícones 1024, 512, 192, 180 (Apple), 32 (favicon), logos horizontais em 2000 px de largura, vertical, símbolo negativo e nome.

## Regras de uso

- Área livre ao redor do logo: no mínimo a largura de uma haste do N (1/8 da altura do ícone).
- Tamanho mínimo: ícone com 24 px; logo horizontal com 120 px de largura.
- Não distorcer, girar, trocar as cores, aplicar sombra ou contorno, nem refazer o nome com outra fonte.
